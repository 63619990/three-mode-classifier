# 三类主导模式判别器（Web3 防骗工具箱）

> 本技能由《价值互联网产业应用蓝皮书（2025）》经 cangjie-distill 蒸馏流水线提取编排，帮助普通用户识别真假 Web3、厘清合规边界、避开资金盘陷阱。

## 功能简介
判断一个产业 Web3 项目属于哪类主导模式（原生型 / 产业变革型 / 链改-资产支持型），并据此选型、设计组织形态与合规路径。
  当用户/企业想"上链"却不知走哪条路、对三类模式的差异与合规边界拿不准时使用。
  触发信号："我们想做个通证/上链项目""传统产业怎么用 Web3 转型""用充电桩/电站收益权融资、发 RWA"。
  不适用于：纯 RWA 工程落地流程（见 S8 RWA 路径）、真假 Web3 识别（见 S4 W-ABCD）、纯合规红线判定（见 S2 合规红线）。

## 安装方式

### 方式一：从 ClawHub 一键安装（推荐）
在 ClawHub 搜索 `three-mode-classifier`，或用 CLI：
```bash
clawhub skill install three-mode-classifier
```

### 方式二：从 GitHub 安装
```bash
git clone https://github.com/63619990/three-mode-classifier.git
cp -r three-mode-classifier/ ~/.workbuddy/skills/
```
重启 WorkBuddy 后，对话出现相关信号即自动激活。

### 方式三：手动安装
将本仓库 `three-mode-classifier/` 目录整体复制到 `~/.workbuddy/skills/`（Windows 为 `%USERPROFILE%\.workbuddy\skills\`）。
